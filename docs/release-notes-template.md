## Install

1. Download **{{DMG}}** below and open it.
2. Drag **Brew Updates** onto **Drag here to install (Applications)**.
3. Open Brew Updates from Applications and click **Open** when macOS asks about an app downloaded from the internet.
4. Choose when updates run, then click **Set Up**.

Already installed? The app offers this update itself, or choose **Check for App Updates…** in the Brew Updates menu.

**Requires** macOS 15 or later on an Apple silicon Mac, and [Homebrew](https://brew.sh). New to it? See [Getting started](https://github.com/jxman/brew-updates#getting-started).
